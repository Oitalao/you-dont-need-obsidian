# Memory

Two-level index. This file lists only the areas; each area has an index `_index-<area>.md` with one line per note. Before acting, open the index of the subject and the notes linked to it; if nothing is found, search the text of every `.md` file in this folder. New note: a file of its own plus one line in the area index (never here). New area only if none fits: create its index and add one line below.

- [Me](_index-me.md): who the user is, preferences, how to answer and work
- [Work](_index-work.md): clients, contracts, deadlines, document templates
- [Home](_index-home.md): family, bills, car, house, purchases
- [Computer](_index-computer.md): programs, scripts, backups, where each thing is stored
